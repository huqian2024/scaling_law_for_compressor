## 7. 自动几何 QC 漏检检查（只用现有指标）

### 7.1 方法

```text
扫描 case_metrics.csv 的 125 个数值列，区分两类：
  (i) 绝对量：min_gap_m, envelope_clearance_m, min_half_thickness_norm,
      max_thickness_norm, meanline_curvature_xc010/050/090,
      meanline_curvature_rms/max, meanline_max_camber_norm,
      blade_tangential_extent_m, chord_angle_deg, chord_norm, ...
  (ii) 相对量：*_dev_norm, *_change_abs, *_change_rel, contour_*_dev_*,
      meanline_rms_dev_norm（相对“各自基准”的偏差，不是绝对形状质量）
判据：以“ACCEPT 观测极值”为门槛，统计命中 REJECT 数与误伤 ACCEPT 数。
```

### 7.2 可分离的指标（100 样本内）

| 指标 | 简单规则 | 命中 REJECT | 误伤 ACCEPT |
|---|---|---|---|
| `meanline_curvature_xc050` | `< 0.264429`（ACCEPT 最小值） | **9/15**（034,035,062,081,084,089,090,091,092） | 0 |
| `blade_tangential_extent_m` | `< 0.0216829` | 8/15（034,035,036,043,062,089,091,092） | 0 |
| `meanline_max_camber_norm` | `< 0.37757` | 8/15（同上） | 0 |
| `chord_angle_deg` | `< 20.8417` | 8/15（同上） | 0 |
| `meanline_curvature_rms` | `> 0.979677` | 8/15（同上） | 0 |
| `meanline_curvature_rms_change_abs`（相对量） | `> 0.395393` | 10/15 | 0（但属于“偏离基准”度量，不推荐作为形状判据） |

两条简单绝对规则的并集：

```text
curv_xc050 < 0.264429  或  blade_tangential_extent_m < 0.0216829
  -> 命中 11/15 REJECT，误伤 0/85 ACCEPT
  -> 未覆盖：C820033、C820082、C820083、C820100
```

再叠加 `min_gap_m <= 0.0149`：

```text
  -> 命中 12/15（补上 C820083），但误伤 1 个 ACCEPT（C820088）
```

### 7.3 无区分能力的指标

| 指标 | 结果 |
|---|---|
| `min_gap_m` | ACCEPT 0.01489–0.06981，REJECT 0.01490–0.03146，完全重叠；任何阈值都会大量误伤 |
| `min_half_thickness_norm` | ACCEPT 0.00400–0.00750，REJECT 0.00481–0.00625；无法分离 |
| `envelope_clearance_m` | `<= 0` 命中 6/15，但误伤 12/85（全批 18 个负值，仅 6 个被拒） |
| 厚度类（`max_thickness_norm`、`max_thickness_xc`、`max_paired_thickness`） | 与标签无单调关系 |
| 相对量（contour/meanline dev、radius change） | 只在“相对各自基准”的意义上有值，不能作为绝对形状质量 |

### 7.4 这些“可分离”结果能信到什么程度

```text
1) 阈值取自同一批 100 个样本（min ACCEPT / max ACCEPT），
   没有任何独立验证 -> 0 误伤是 in-sample 结果，不是泛化能力。
2) 命中的指标都在描述同一类几何：中弧线中段曲率偏低、切向尺寸偏小、
   弦向角偏小、最大弯度偏小 —— 即“低弯度/紧凑型”叶型。
   但低弯度也可能来自合法的小折转设计（低 Metal2），存在系统性误杀风险。
3) 15 个 REJECT 只有 15 个正样本，阈值选择方差很大；
   换一批样本，0.2644 这类边界很可能偏移。
4) C830 上这 2 条规则会标记 18/57（主要是低 Xmean + 高 K_m 与 ML 背景），
   C840 标记 0/49；但两者都没有人工标签，无法判断标记对错。
5) 没有逐案不合格原因，无法确认被标记的几何特征就是师兄所指的缺陷。
```

```text
结论：现有指标确实存在“可用的信号”，但不足以构成可靠判据。
本轮不把任何 QC 阈值写入代码，也不建议用它们静默淘汰样本。
建议的用法：软标记（flag）+ 人工复核 + 记录 reason_code，
待有独立标注样本后再评估是否升级为硬门。
```

### 8.2 收紧了什么、依据是什么

## 11. 自动 QC 需要补充的能力（建议，未实现）

```text
1) 绝对形状描述量：目前大量指标是“相对各自基准的偏差”，
   无法回答“这个叶型本身是否合理”。需要独立的绝对量（曲率、弯度、
   厚度分布、通道收敛性等）与跨样本可比阈值。
2) 独立标注集：用不同于 C820 的样本（例如冻结 SS1/SS2 下新生成的一批，
   或 C830/C840 的人工复核结果）验证阈值，避免同批拟合。
3) 逐案原因编码：师兄补充拒收原因后，把缺陷类型映射为量化的形状特征，
   而不是用单一“曲率小/尺寸小”代理。
4) 软门机制：先 flag + 人工复核，统计误杀率；确认后才升级为硬门。
5) 与参数约束分工：参数约束只负责“避免明显极端”，
   细节形状问题留给生成后 QC，避免把参数空间压得过窄。
```
